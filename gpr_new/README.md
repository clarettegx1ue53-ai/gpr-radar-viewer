# 三维 GPR 数据可视化

基于 Python 自带的 Tkinter 图形界面和 NumPy，实现三维 `.npy` 雷达数据的三个正交切面浏览。界面会在同一画布中并排显示 X、Y、Z 切面，并显示距离刻度及当前切片位置。

## 坐标定义

- X：长度 1000 m
- Y：宽度 1.5 m
- Z：深度 1.25 m（深度向下增加）
- 默认将 NPY 数组按 `[Z, Y, X]` 解释，即 `shape=(深度采样数, 宽度采样数, 长度采样数)`。
- 若文件数组顺序为 `[X, Y, Z]`，载入后在左侧“NPY 数组维度顺序”中选择 `XYZ`。
- 也支持 `[Y, X, Z]`（宽度、长度、深度）顺序；复数数据在首维较小、后两维较大时会自动选择该顺序。也可在左侧手动切换。
- 复数 GPR 数据显示幅值 `|I+jQ|`，实数数据按原值显示。

坐标会按各维首末采样点线性映射到上述物理范围。切面滑块可浏览每个方向的采样位置；灰度范围按数据有限值的第 1 至第 99 百分位自动设置。

## 运行

需要 Python 3 和 NumPy；Tkinter 通常随 Python 安装提供。

```bash
python -m pip install numpy
python gpr_viewer.py
```

点击“导入 NPY 文件”选择三维数值 `.npy` 文件。程序以只读内存映射方式载入文件，适合较大的数据体。
